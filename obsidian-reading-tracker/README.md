# Obsidian Reading Tracker

A small Obsidian setup for tracking books and taking reading notes.

## Contents
- `Reading Tracker.md` – dashboard: currently reading (with progress %), up next, finished this year, yearly stats, top rated, collected quotes, abandoned.
- `Templates/Book Template.md` – template for a new book note (properties + sections for summary, key ideas, chapter notes, quotes, takeaways, review).
- `Books/` – one note per book (contains an example you can delete).

## Setup
1. Copy this folder into your Obsidian vault.
2. Install and enable the **Dataview** community plugin (Settings → Community plugins). Turn on *Enable inline queries* in Dataview's settings for the progress line in each book note.
3. Enable the core **Templates** plugin and set its template folder to `Templates`.
4. Pin or bookmark `Reading Tracker.md`.

If you put the folder somewhere other than the vault root, change `FROM "Books"` in the dashboard to the full path, e.g. `FROM "Reading/Books"`.
